# Monochrome Stealth Messenger (Aegis-52)

Ультразащищенный мессенджер в минималистичном монохромном дизайне с функциями уровня Telegram (личные чаты, группы, каналы, папки), прямой передачей данных в локальной сети (LAN P2P), поддержкой собственного слепого сервера и встроенной крипто-лабораторией из 52 алгоритмов, где даже создатель мессенджера и владелец сервера физически не могут прочитать переписку.

- **Маршрутизация и работа с вашим сервером (Трибридный транспорт)**: Автоматическая маршрутизация сообщений по трем каналам без участия пользователя: **1) LAN P2P (UDP Discovery + TCP Fast-Frame)** для мгновенной прямой связи внутри одной Wi-Fi/локальной сети без интернета; **2) Ваш кастомный сервер (WebSocket/REST Blind Relay)** с возможностью указать IP/домен вашего сервера в настройках и получить готовый код серверного узла прямо внутри приложения; **3) Облачный Zero-Knowledge релей** для доставки зашифрованных пакетов, когда абоненты в разных сетях.
- **Аутентификация и защита от прослушивания создателем (Zero-Knowledge)**: Двухконтурный вход — привязка номера телефона (SMS-верификация) + подтверждение через системный Google-аккаунт (`CredentialManager`) с локальной генерацией ключевой пары **X25519 + Ed25519** и секретного мастер-ключа прямо на устройстве. На сервер передаются исключительно слепые шифротексты и публичные ключи.
- **Функционал уровня Telegram**: Личные чаты, группы, широковещательные каналы, настраиваемые папки чатов («Все», «Личные», «Группы», «Каналы», «LAN Радар», «Секретные»), закрепленные сообщения, ответы (Reply), реакции, таймер автоудаления и передача вложений/голосовых заметок.
- **Визуальный стиль и маскировка (Monochrome Stealth & Camouflage)**: Строгий монохромный интерфейс (глубокий обсидиан, графит, матовый белый и технический моноширинный шрифт) с функцией **«Режим маскировки» (Decoy Camouflage)** — по одному нажатию или вводу ложного PIN-кода мессенджер мгновенно превращается в обычное системное приложение «Заметки и Калькулятор» до ввода секретной команды в калькуляторе.

## 1. Overview & Core Concept

- **Что делает приложение**: Объединяет привычное удобство Telegram с военной криптографией и автономной связью. Пользователь общается в личных чатах, группах и каналах, распределяет переписки по папкам, видит абонентов поблизости через встроенный LAN-радар и может в один клик замаскировать приложение под системный калькулятор/заметки.
- **Криптографическое ядро (Отбор из 52 алгоритмов -> Протокол Aegis-52)**:
  В приложение встроен движок-бенчмарк, содержащий **52 криптографические схемы и протокола** (от классических AES-GCM и ChaCha20 до каскадных гибридов с обфускацией трафика и защитой от квантового анализа). На основе автоматического стресс-теста скорости, энтропии и криптостойкости по умолчанию активируется победитель — **каскадный протокол Aegis-52**:
  1. **Слой согласования ключей**: Эфемерный обмен ключей **X25519 (Elliptic Curve Diffie-Hellman)** + **Double Ratchet** (новый ключ на каждое сообщение, прямая и обратная секретность).
  2. **Слой двойного симметричного шифрования (Cascade AEAD)**: Внутренний контур **ChaCha20-Poly1305** + внешний контур **AES-256-GCM** с независимыми производными ключами через **HKDF-SHA3-512**.
  3. **Слой защиты метаданных (Hyper-Fast Frame Padding)**: Выравнивание пакетов до фиксированных блоков и обфускация заголовков, чтобы по размеру пакета на сервере или в LAN нельзя было определить тип сообщения.
- **Что делает ваш сервер (Blind Zero-Knowledge Relay + Turn/Directory)**:
  Ваш сервер выступает как «слепой коммутатор»:
  - Хранит публичный справочник ключей (`PublicKey Directory`), чтобы пользователи находили друг друга по хэшу номера телефона или `@username`.
  - Держит быстрые WebSocket-туннели для мгновенной пересылки зашифрованных конвертов (`EncryptedEnvelope`) и помогает устройствам за NAT обменяться IP-адресами.
  - В разделе **«Сервер и Узел связи»** приложения доступен конфигуратор адреса вашего сервера, живая телеметрия пинга и встроенный готовый скрипт сервера (Node.js / Docker), который вы можете скопировать и запустить на своем VPS одной командой.

## 2. User Experience & Visual Design

### Ключевые пользовательские сценарии (User Flows)

1. **Вход, SMS-привязка и локальная генерация ключей**:
   - Пользователь подтверждает вход, вводит номер телефона и код подтверждения SMS, после чего на устройстве за миллисекунды генерируется криптографическая личность (публичный отпечаток ключа и 12-словная резервная фраза).
   - Пользователь задает секретный код разблокировки (например, `7391=`) для выхода из режима маскировки.
2. **Главный экран мессенджера (Папки, Чаты, Группы, Каналы)**:
   - Горизонтальная лента папок вверху: **Все**, **Личные**, **Группы**, **Каналы**, **LAN-сеть**, **Секретные**.
   - Список диалогов с индикаторами канала доставки: иконка прямого соединения `LAN` (если абонент в одной локальной сети), `SRV` (через ваш сервер) или `E2E` (облачный релей).
   - Быстрое создание личного чата, защищенной группы или авторского канала с публикацией постов и счетчиком просмотров.
3. **Экран переписки и инспектор шифрования**:
   - Мгновенная отправка текста, ответов (Reply), реакций, файлов, голосовых заметок и сообщений с таймером самоуничтожения.
   - При нажатии на плашку безопасности чата открывается **Инспектор пакета** — можно увидеть реальный зашифрованный шестнадцатеричный/Base64 пакет, отпечаток ключа собеседника (Safety Number) и маршрут доставки (`LAN P2P 1.4 ms` / `Server Relay`).
4. **LAN-Радар и прямая локальная связь**:
   - Экран обнаружения устройств в локальной сети (UDP Multicast / Broadcast + прямой ввод локального IP:Port). Позволяет находить абонентов в одной Wi-Fi сети и обмениваться сообщениями напрямую по TCP-сокетам даже при полном отключении интернета.
5. **Крипто-Лаборатория (52 алгоритма и выбор самого мощного)**:
   - Интерактивный каталог всех **52 исследованных идей и крипто-схем**, разбитых на 5 поколений (симметричные шифры, AEAD-потоки, постквантовые гибриды, стеганографическое кадрирование, каскад Aegis-52).
   - Кнопка **«Запустить стресс-тест 52 алгоритмов»**, которая в реальном времени тестирует их на процессоре телефона, строит таблицу скорости (МБ/с), задержки (мкс) и уровня защиты, наглядно доказывая превосходство выбранного протокола **Aegis-52**.
6. **Режим максимальной маскировки (Stealth Camouflage Mode)**:
   - В шапке приложения есть малозаметная кнопка маскировки (иконка щита/заметок). При нажатии мессенджер мгновенно скрывает все чаты и превращается в минималистичное приложение **«Системные Заметки и Калькулятор»**, которое реально работает как калькулятор и блокнот.
   - Чтобы вернуться в мессенджер, достаточно набрать свой секретный код в калькуляторе и нажать `=`.

### Визуальная система и эстетика

- **Эстетическое направление**: Утилитарный монохромный минимализм (*Stealth Monochrome Utility*). Никаких ярких кричащих градиентов или лишнего декора — интерфейс выглядит как строгий профессиональный системный инструмент или приложение для заметок.
- **Цветовая палитра (Theme Tokens)**:
  - `--background`: `#0B0B0C` (глубокий матовый уголь в темной теме) / `#F7F7F5` (бумажный монохром в светлой теме маскировки).
  - `--surface`: `#141416` (графитовая карточка) с тонкими рамками `#262629` (`1.dp`).
  - `--primary`: `#F2F2F2` (чистый контрастный белый/платиновый акцент для активных элементов).
  - `--secondary`: `#8E8E93` (приглушенный цинк для метаданных, времени и сетевых статусов).
  - `--accent`: `#D4D4D8` (монохромный металлик для индикаторов LAN и крипто-бейджей).
- **Типографика**:
  - Заголовки и текст сообщений: **Inter** — идеальная читаемость и визуальная маскировка под стандартное системное приложение.
  - Криптографические ключи, сетевые пинги, хэши и калькулятор маскировки: **JetBrains Mono** — четкий технический моноширинный шрифт.

## 3. Key Product Decisions & Trade-Offs

- **Решение 1: Каскадный протокол Aegis-52 вместо одиночного шифра**
  - *Выбранный подход*: Двухслойная схема `ChaCha20-Poly1305` + `AES-256-GCM` поверх эфемерного обмена `X25519` и `HKDF-SHA3-512` с выравниванием размера фреймов.
  - *Почему*: Даже если в одном из стандартов в будущем найдут математическую уязвимость, второй независимый шифр с собственным производным ключом сохранит полную неприкосновенность переписки, при этом аппаратное ускорение на Android обеспечивает шифрование менее чем за `0.2 мс` на сообщение.
- **Решение 2: Трибридная сеть (LAN P2P + Кастомный сервер + Облачный Zero-Knowledge релей)**
  - *Выбранный подход*: Сообщения параллельно поддерживают прямые локальные TCP/UDP сокеты в локальной сети, подключение к пользовательскому серверу по WebSocket/HTTP и облачную синхронизацию зашифрованных конвертов.
  - *Почему*: Приложение работает сразу «из коробки» между любыми устройствами, позволяет общаться вообще без интернета по Wi-Fi (LAN) и дает вам полный контроль над собственным сервером.
- **Решение 3: Маскировка под «Заметки и Калькулятор» (Stealth Camouflage)**
  - *Выбранный подход*: Встроенный полнофункциональный монохромный экран прикрытия с разблокировкой через секретную комбинацию клавиш.
  - *Почему*: Самый надежный шифр бесполезен, если посторонний человек видит на экране открытый мессенджер. Монохромный дизайн и мгновенный переход в режим заметок/калькулятора обеспечивают визуальную незаметность.

### Модель данных и хранение

- **Локальное зашифрованное хранилище (Room Database)**:
  - `ConversationEntity`: чаты (Личный, Группа, Канал, Секретный), папка (`folderTag`), закрепленное сообщение, отпечаток публичного ключа, статус LAN-узла, настройки таймера автоудаления.
  - `MessageEntity`: локально расшифрованный текст, зашифрованный сетевой пейлоад (`ciphertextHex`), криптографическая подпись, алгоритм (`AEGIS-52`), транспорт доставки (`LAN_P2P`, `CUSTOM_SERVER`, `CLOUD_RELAY`), время доставки, ответ (`replyToId`), реакции и вложения.
  - `LanPeerEntity`: обнаруженные в локальной сети пиры (IP-адрес, порт, имя узла, публичный ключ, задержка в мс).
  - `DecoyNoteEntity`: заметки для режима маскировки, чтобы экран прикрытия выглядел абсолютно естественно.
- **Облачный и серверный слепой релей (Firestore + Custom Server WebSocket)**:
  - `users/{userId}`: публичный профиль (отображаемое имя, хэш телефона для поиска контактов, публичный ключ `X25519`, статус). Приватные ключи никогда не покидают устройство.
  - `envelopes/{envelopeId}` и `rooms/{roomId}/envelopes/{envelopeId}`: зашифрованные конверты (`senderUid`, `recipientUid`, `ephemeralPubKey`, `nonce`, `ciphertext`, `macTag`, `protocolVersion`, `createdAt`), которые сервер и база данных не способны расшифровать.

### Интерактивные переходы и привязка состояний

- **Переключатель папок и фильтр чатов**: Мгновенная реактивная фильтрация `StateFlow` по папкам (`Все`, `Личные`, `Группы`, `Каналы`, `LAN`, `Секретные`) и поисковому запросу без задержек.
- **Создание чата / группы / канала**: Модальный мастер с выбором типа (Личный чат по номеру/никнейму/LAN-пиру, Группа с участниками или Канал с подписчиками), выбором папки и уровня автоудаления.
- **Живой LAN-радар**: Фоновый корутин-сервис рассылает и слушает UDP-маяки в локальной сети, автоматически добавляет найденные устройства в список пиров и открывает прямой TCP-канал для мгновенной отправки пакетов.
- **Крипто-лаборатория 52 алгоритмов**: Реальный прогон тестовых блоков данных через 52 конфигурации шифрования с живой шкалой прогресса, сортировкой по индексу безопасности и детальной карточкой каждого протокола.
- **Экран настройки вашего сервера**: Позволяет ввести URL вашего сервера, проверить соединение (Ping / Handshake) и скопировать готовый исходный код слепого релей-сервера для запуска на вашем хостинге.
